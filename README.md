# Meeting Recorder (working name: Elegant)

A personal macOS app that notices when you are in an online call, offers to record it, and produces a transcript and summary entirely on your own machine.

The macOS app, local speech pipeline, evidence-backed Summaries and Meeting chat are implemented. Real-recording quality, offline native operation and M4 performance gates still need device testing; implementation and passing automated tests do not establish those results.

Start with [`docs/design.md`](./docs/design.md), then [`GLOSSARY.md`](./GLOSSARY.md). For AI contracts, read [`docs/ai-brief.md`](./docs/ai-brief.md). See [`evaluation/README.md`](./evaluation/README.md) for synthetic and private evaluation commands, and [`docs/ai-testing.md`](./docs/ai-testing.md) for local setup, device checks and recovery.
