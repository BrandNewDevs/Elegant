# Meeting Recorder (working name: Elegant)

A personal macOS app that notices when you are in an online call, offers to record it, and produces a transcript and summary entirely on your own machine.

Status: design stage. Start with [`docs/design.md`](./docs/design.md), then [`GLOSSARY.md`](./GLOSSARY.md). If you are working on the AI side, read [`docs/ai-brief.md`](./docs/ai-brief.md).
