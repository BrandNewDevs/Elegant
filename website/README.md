# Website

The public site for the app: a landing page and an install guide. TanStack Start (prerendered to static HTML) with Tailwind 4 and shadcn/ui.

```sh
pnpm install
pnpm dev          # http://localhost:3000
pnpm run typecheck
pnpm run build    # static site in dist/client
```

- Pages are file routes in `src/routes/`. `src/routeTree.gen.ts` is generated by the build and dev server; don't edit it.
- The product name and repository come from `app/src/config.ts` through `src/site.ts`; don't hard-code them.
- Add shadcn components with `pnpm dlx shadcn@latest add <name>`; they land in `src/components/ui/`.
- Brand assets in `public/` are copies from `docs/brand/`.
- Deploy `dist/client` to any static host.
